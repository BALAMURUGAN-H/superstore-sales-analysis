# 📊 Superstore Sales Analysis using Python

A complete Exploratory Data Analysis (EDA) project performed on the Superstore dataset using Python. This project focuses on understanding sales performance, profitability, customer behavior, regional trends, and business opportunities through data analysis and visualization.

---

## 📌 Project Overview

The objective of this project is to analyze retail sales data and generate meaningful business insights that can support decision-making. The analysis includes data cleaning, exploratory data analysis (EDA), KPI calculation, business insights, and a final dashboard created using Python.

This project demonstrates my ability to work with real-world business data using Python, Pandas, NumPy, and Matplotlib.

---

## 🎯 Business Objectives

* Analyze overall sales and profit performance.
* Identify the best-performing regions and customer segments.
* Compare sales and profit across product categories.
* Find high-performing and loss-making sub-categories.
* Study monthly sales trends and seasonal patterns.
* Understand the impact of discounts on profitability.
* Build a professional business dashboard using Python.

## 💡 Key Business Insights

* **West** is the highest-performing region in terms of sales, profit, and orders.
* **Technology** generates the highest sales and profit among all categories.
* **Consumer** is the most valuable customer segment.
* **November** records the highest overall monthly sales.
* **Tables** is the biggest loss-making sub-category.
* Discounts show a **weak negative relationship** with profitability.
